# Tools

Standalone helper apps that sit beside CardVault rather than inside it. Each
has its own README and runs on its own.

| Tool | What it does |
|---|---|
| [`tcgdex-harvester`](tcgdex-harvester/) | A local web app that downloads every card image and its data from the TCGdex API, rate-limited, with a live dashboard, pause/resume and an interactive queue. Used to build an OCR training set. |
